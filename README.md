# Netflix Exploratory Data Analysis

## Project Overview

This project performs Exploratory Data Analysis (EDA) on a cleaned Netflix dataset.

The objective is to identify patterns, trends, distributions, and relationships in Netflix Movies and TV Shows.

## Dataset

The dataset contains information about Netflix content, including:

- Content type
- Title
- Country
- Release year
- Rating
- Duration
- Genre
- Date added

## Objective

The main objective of this project is to explore the Netflix dataset using statistical analysis and data visualization techniques.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## EDA Methodology

The following steps were followed:

1. Loaded the cleaned Netflix dataset.
2. Inspected the dataset structure and dimensions.
3. Checked column names and data types.
4. Verified missing values.
5. Analyzed categorical and numerical variables.
6. Grouped and aggregated data to identify patterns.
7. Created visualizations using Matplotlib and Seaborn.
8. Compared Movies and TV Shows.
9. Analyzed trends across years and months.
10. Interpreted the results and documented observations.

## EDA Questions

The project analyzes 15 questions related to:

1. Distribution of Movies and TV Shows
2. Netflix titles by release year
3. Top countries associated with Netflix titles
4. Distribution of content ratings
5. Most common genres
6. Distribution of movie durations
7. Netflix titles added by year
8. Netflix titles added by month
9. Ratings by content type
10. Countries by content type
11. Movies and TV Shows added over time
12. Release year vs year added
13. Directors with the most titles
14. Most common movie durations
15. Rating composition by content type

## Conclusion

Exploratory Data Analysis helped us understand important patterns and relationships within the Netflix dataset. The visualizations and statistical analysis provide a clearer understanding of Netflix's content library and its characteristics.
